# SeeON 우주 눈 훈련 (웹)

어린이 눈 운동 게임 SeeON의 웹 버전입니다. 주소는 **https://seeon.equald.kr** 입니다.

- 게스트 모드: 로그인 없이 바로 플레이할 수 있고, 기록은 이 기기에만 저장됩니다.
- 로그인 모드: 카카오나 구글로 로그인하면 보호자 계정에 조종사(아이)를 최대 6명까지 만들 수 있습니다. 기록은 계정에 저장되어 여러 기기에서 이어서 할 수 있습니다.
- 보호자 리포트: 게임 기록을 분석해 그래프와 생활 가이드를 보여줍니다.

## 구조
| 경로 | 내용 |
|---|---|
| `src/game.html` | **게임 원본**(단일 파일). 수정은 여기서 합니다. |
| `index.html` | 배포용 페이지. `node tools/build.mjs`로 생성하며 직접 수정하지 않습니다. |
| `config.js` | Supabase 주소와 공개 키. 값이 비어 있으면 게스트 모드로만 동작합니다. |
| `vendor/` | three.js r128, supabase-js v2(UMD) — 외부 CDN 없이 사이트에서 직접 제공합니다. |
| `supabase/schema.sql` | DB 테이블, 보안 규칙(RLS), 동기화 함수 `seeon_sync` |
| `docs/SETUP.md` | 처음 연결하는 방법(GitHub Pages, Supabase, 카카오, 구글, DNS) |

## 수정 → 배포
```bash
# src/game.html 수정 후
node tools/build.mjs
git add -A && git commit -m "…" && git push   # 1~2분 뒤 자동 반영
```

## 기록 동기화 방식
- 게임은 먼저 `localStorage`(`seeon.*`)에 저장하고, 로그인 상태라면 몇 초 뒤 서버로 보냅니다. 오프라인일 때 쌓인 기록은 대기열에 남았다가 다시 전송합니다.
- 한 판 기록에는 고유 `cid`가 붙어 중복 저장되지 않습니다(`unique(profile_id, cid)`).
- 여러 기기의 진행 상태를 합치는 규칙은 다음과 같습니다.
  - 별·해금·레벨: 더 큰 값을 남깁니다.
  - 눈 휴식·습관·화면 시간: 모두 합칩니다.
  - 그 밖의 값: 마지막에 보낸 값을 씁니다.
- 보안: 모든 테이블에 RLS를 켜 두어, 로그인한 계정이 자기 데이터만 읽고 쓸 수 있습니다.
