# SeeON 우주 눈 훈련 (웹)

어린이 눈 운동 게임 SeeON의 웹 버전입니다. 주소는 **https://seeon.equald.kr** 입니다.

- 게스트 모드: 로그인 없이 바로 플레이할 수 있고, 기록은 이 기기에만 저장됩니다.
- 회원 모드: 보호자(만 14세 이상)가 이메일로 가입(필수·선택 동의, 이메일 인증)하면 조종사(아이)를 최대 6명까지 만들고, 기록이 계정에 저장되며 보호자 리포트를 볼 수 있습니다. (docs/MEMBERS.md)
- 보호자 리포트: 게임 기록을 분석해 그래프와 생활 가이드를 보여줍니다.

## 기록 동기화 방식
- 게임은 먼저 `localStorage`(`seeon.*`)에 저장하고, 로그인 상태라면 몇 초 뒤 서버로 보냅니다. 오프라인일 때 쌓인 기록은 대기열에 남았다가 다시 전송합니다.
- 한 판 기록에는 고유 `cid`가 붙어 중복 저장되지 않습니다(`unique(profile_id, cid)`).
- 여러 기기의 진행 상태를 합치는 규칙은 다음과 같습니다.
  - 별·해금·레벨: 더 큰 값을 남깁니다.
  - 눈 휴식·습관·화면 시간: 모두 합칩니다.
  - 그 밖의 값: 마지막에 보낸 값을 씁니다.
- 보안: 모든 테이블에 RLS를 켜 두어, 로그인한 계정이 자기 데이터만 읽고 쓸 수 있습니다.
- 아직 서버에 못 보낸 변경은 `seeon.cloud.dirty` 로 기억해요. 한 판 끝내고 바로 새로고침·창 닫기를 해도, 같은 조종사를 다시 불러올 때 먼저 보내요 (창을 숨기거나 닫을 때도 바로 보내요).
- 계정 창의 **🗑 조종사 지우기**: 조종사와 그 훈련 기록을 서버에서 지워요(`seeon_delete_profile`). 지금 조종사를 지우면 다른 조종사로 바뀌어요.

## 조종사 레벨 · 배지
- 레벨은 **1~50**이에요(50이 최고). 레벨 n → n+1에 필요한 경험치는 `100 + (n-1)×40` XP이고, 한 판에 별 1/2/3개면 10/20/40 XP예요.
- 5레벨마다 계급이 바뀌고 계급 배지를 받아요: 5 🚀 우주 조종사 · 10 🛰️ 은하 탐험가 · 15 🌠 별빛 항해사 · 20 🪐 행성 수호대 · 25 ☄️ 혜성 기장 · 30 🌌 은하 함장 · 35 🛡️ 우주 대장 · 40 👑 별의 사령관 · 45 💎 우주 영웅 · 50 🏆 전설의 우주 영웅 (1~4는 🐣 견습 조종사).
- 배지는 모두 38개예요 (훈련·꾸준히·별·여러 게임·우주 모험·계급·눈 측정).
- 홈 화면 게임은 18개 카드예요. 예전 '우주 동화나라' 카드 안에 있던 동화책 읽기·숫자 빙글빙글·지그재그 따라가기를 각각 따로 보여 줘요.

## 슈퍼 계정 (테스트·시연용)
- `python3 tools/super_account.py [이메일]` 을 실행하면 비밀번호를 새로 만들어 `super_account.sql` 을 만들어요. 이 파일은 저장소에 올리지 않아요(.gitignore).
- Supabase SQL Editor 에서 실행하면 이메일 인증이 끝난 계정과 조종사 3명이 만들어져요: 슈퍼 조종사(모두 완료·레벨 50·배지 전부), 지도1 끝 연습(49행성까지), 지도2 끝 연습(99행성까지).
- 우주 모험 지도의 목표 지점에 있는 **🎬 축하 · 다음 지도 연출 다시 보기** 버튼으로 기록을 바꾸지 않고 지도 넘어가는 연출을 다시 볼 수 있어요 (마지막 지도는 완주 축하).

## 헷갈리는 색깔 5단계
- 15문제 중 13개 이상 별 3개, 10개 이상 별 2개. 별 3개를 받으면 다음 단계가 열려요.
- 1단계 4색·천천히 → 2단계 5색 → 3단계 5색·4초 → 4단계 6색·3.2초 → 5단계 7색·2.5초 (뜻과 색이 다른 문제 비율 60%→100%)
- 나가기 창이 떠 있는 동안에는 시간이 멈춰요. 시간 안에 못 고르면 틀린 것으로 세요.
- 우주 모험에도 나와요: 기존 행성 순서는 그대로 두고, 약 150개 중 8~9개 행성에 끼워 넣어요.
- 게임 별 최대치: 171 → 186개 (별 대부호 배지·슈퍼 계정 포함)

## 단계별 난이도 (2026-09 조정)
- 반짝 별 세기: 별 3~5개·1초 → 4~7개·0.7초 → 6~9개·0.5초(+세지 않는 파란 행성 2개) → 8~12개·0.35초(행성 3개) → 10~15개·0.25초(행성 4개). 보기 수 3→5개, 서로 가까운 숫자.

## 모바일
- 게임·우주 모험 화면에서는 두 번 누르기·두 손가락 확대를 막아요 (게임을 닫으면 원래대로).
- 마우스가 없는 기기에서는 :hover 효과를 쓰지 않아요 (터치한 자리에 테두리가 남아 보이던 문제).
- 버튼 줄 맞춤(`balanceRows`): 단계 버튼·색 버튼·보기 버튼이 줄을 넘길 때 마지막 줄에 하나만 떨어지지 않게 3+2, 4+3 처럼 나눠요. 휴대폰(한 줄 2개)에서는 3칸으로 줄이고, 그래도 하나가 남는 개수(7개)는 마지막 단계를 넓은 카드로 보여 줘요. 결과 화면 버튼 3개는 같은 폭으로 세로로 놓아요.

## 단계 이름 통일 · 5단계 체계 (2026-10)
- 모든 게임은 1~5단계예요: **1단계(매우 쉬움) · 2단계(약간 쉬움) · 3단계(보통) · 4단계(어려움) · 5단계(매우 어려움)**. 별빛 잇기는 6단계(도전)·7단계(마스터)까지 그대로 있어요.
- 3단계였던 게임(운석 부수기·슝슝 야구공·숫자 빙글빙글·번개 도형 터치·희미한 별 찾기)은 2·4단계를 새로 넣어 5단계가 됐어요.
  - 예전 1·2·3단계(쉬움·보통·어려움) → 새 1·3·5단계로 옮겨요. 별·해금은 새 칸(`seeon.stars.<게임>5.N`, `seeon.unlock.<게임>5`)에 저장하고, 예전 칸은 남겨 두되 세지 않아요(서버 합치기 규칙이 '큰 값'이라 지우지 않아요).
  - 옮기기(`migrateStage5`)는 처음 열 때와 계정 기록을 받을 때마다 실행되고, 여러 번 해도 결과가 같아요. 옮긴 값은 계정에도 저장돼요.
  - 예전 게임 기록(seeon_records)의 단계 번호는 읽을 때 바꿔요: 새 기록에는 `m.s5=1` 표시가 붙어요.
  - 게임 단계 별 최대: 186 → 216개. 우주 모험 행성 단계도 1~5단계로 나눠져요(게임 순서는 그대로).
- 자유 훈련 게임(빙글빙글 원판·달님 그네·지그재그 따라가기·우주 나침반)도 1~5단계로 시작해요(점수·잠금 없음, 게임 중에 빠르기를 바꿀 수 있어요).
- 슈퍼 계정: `tools/super_account.py` 가 새 칸까지 채워요. 이미 만든 슈퍼 계정은 `super_stage5.sql`(비밀번호 없음)로 새 2·4단계를 채울 수 있어요.

## 플레이 화면 지시문
- 모든 게임 플레이 화면 위쪽에 한 줄 지시문이 나와요(`playHint`): 무엇을 보는지 · 어떻게 누르는지 · 빠르고 정확하게 · 머리 고정 등. 설명서를 읽지 않고 들어와도 바로 할 수 있게.

## 달님 그네 (2026-10)
- 한 번에 30초 후 자동으로 끝나요 (나가기·방법 창이 떠 있는 시간은 빼요). 끝나면 훈련 기록이 남고 다음 단계·다시 하기를 고를 수 있어요.

## 2026-10 묶음 수정 ② — 야구공 7단계 · 원판 줄 · 헷갈리는 색깔 · 숨은 외계인
- 슝슝 야구공 7단계: 1~3 일반 · 4~5 숙련 · 6(선수급) · 7(프로 선수급). 공이 보이는 시간 1단계 약 1.2초 → 7단계 약 0.2초(60Hz 약 12프레임). 우주 모험에는 5단계까지만 나와요. 게임 별 최대 222개.
- 빙글빙글 원판: 1~5단계 = 도넛 모양 글자 줄 1~5줄. 읽을 줄 하나만 금색으로 빛나고, 한 줄 읽을 시간(5~10초)이 지나면 다음 줄로 넘어가요('⏭ 다음 줄' 버튼도 있어요).
- 헷갈리는 색깔: 예전 3단계가 새 1단계. 4·5단계는 2초·1.5초 + 색 버튼 자리가 문제마다 바뀌어요. 예전 3·4·5단계 기록 → 새 1·2·3단계(`nova2` 칸, 기록 표시 `m.s2`).
- 숨은 외계인 찾기: 예전 2단계가 새 1단계(20개 중 Q) → 5단계 52개 중 R(거울 글자 Я 섞임). 예전 2~5단계 기록 → 새 1~4단계(`search2` 칸, `m.s2`).
- 슈퍼 계정 보정: `super_stage5.sql` 이 위 새 단계까지 모두 채워요.

## 큰 화면 권장 · 연구 데이터 1~3단계 (2026-10)

- **판 요약 `m.d`**: 모든 게임이 한 판을 마치면 기록의 `m.d`에 공통 필드(단계·변화·도전 횟수·시행·정확도·반응시간 요약·환경)와 게임별 설정(`cfg`)·지표(`gx`)를 함께 저장해요. 필드 설명은 [`docs/DATA.md`](docs/DATA.md).
- **연구 활용 동의(선택)**: 가입 화면의 선택 항목(전체 동의에 포함하지 않음)과 계정 창 스위치. `seeon_consents.kind='research'`, `seeon_set_research(p_on)`. 서버에 `supabase/research.sql`을 한 번 실행해야 해요.
- 개인정보처리방침에 '연구 활용' 항목 추가 (시행 2026-10-12). 관리자 기록 목록에 🔬 상세 표시.
- 관리자 게임 분석 탭 '📥 내려받기': 게임 분석 요약 CSV(게임·단계·주별)와 연구용 판 단위 CSV(연구 동의 계정만, 가명 ID). 서버에 `supabase/research_export.sql` 실행 필요.
- 남은 일: 시행 단위 원자료(`seeon_trials`).

## 📖 도서 쿠폰 등록 · 체험 제한 (2026-10)
- **흐름**: 회원가입은 누구나(무료) → 로그인한 상태에서 '📖 쿠폰 등록'을 하면 모든 단계·우주 모험·보호자 리포트가 열려요. 가입 화면에서 쿠폰을 함께 넣으면 가입과 동시에 등록돼요(선택).
- **체험 범위**: 비회원과 쿠폰 미등록 회원은 게임마다 2단계 · 우주 모험 10번째 행성까지(관리자 '쿠폰' 탭에서 바꿀 수 있음). 미등록 회원 기록은 계정에 저장돼요.
- **기존 회원**: `coupons.sql`을 처음 실행할 때 이미 가입해 있던 계정은 `legacy`로 쿠폰 없이 전체 이용해요(한 번만 처리).
- **쿠폰 번호**: `python3 tools/make_coupons.py BOOK1 1100 <폴더>` → 인쇄용 `coupons_BOOK1_print.csv`(비밀 · `.gitignore`)와 `coupons_BOOK1_insert.sql`(해시만). 형식 `XXXX-XXXX-XXXX`(무작위 11자 + 검사 문자, 30종 글자, 0·1·I·L·O·U 없음).
- **서버**(`supabase/coupons.sql`): `seeon_coupon_redeem`(같은 쿠폰 동시 등록은 한 명만 · 틀린 번호 시간당 20번 제한) · `seeon_my_access` · 가입 시 쿠폰 처리 트리거(쿠폰이 안 맞아도 가입은 막지 않음) · `seeon_entitlements`(coupon/legacy) · 예외 이메일 · 설정 스위치 · 관리자 함수.
- **관리자 '쿠폰' 탭**: 쿠폰 현황, 회원 이용 현황(쿠폰 등록/기존/예외/미등록), 번호·일련번호 찾기, 풀기/막기, 사용 내역 CSV, 스위치, 예외 이메일.
- SQL로 계정을 직접 만드는 `tools/super_account.py`는 `seeon_entitlements`에 legacy로 넣어요.

## 2026-10 게임 안내·조작 개선
- 모든 게임 시작 화면: 핵심 지시 한 줄을 큰 글씨(`p.lead`)로, 설명은 짧게. 게임 중 지시문(`.topmsg`)도 크게.
- 쌍둥이 행성: 화면 한가운데 희미한 손가락 자리, 두 행성이 가운데로 모이는 모습(점선 3단계)을 희미하게 반복 표시.
- 눈 고정 훈련(주변 별 찾기·희미한 별 찾기): 시작 화면에 노란 큰 글씨 "눈은 화면 가운데에 딱!", 3-2-1 동안 "가운데를 바라봐요", 시작 때 가운데 표시에 빛 고리.
- 속도 조절(원판·숫자 빙글빙글·지그재그·달님): 🐢/🐇 대신 '느리게'·'빠르게' 글자 버튼, 누를 때마다 큰 안내 문구(`speedCue`).
- 달님 그네: 좌우 그네 대신 무작위 방향·빠르기로 부드럽게 움직임. 가끔 금빛으로 반짝일 때 화면을 톡(스페이스) → 반짝 맞힘·반응시간 기록(`m.d`).

## 2026-10 게임 수정 ④ — 가보르 · 도형 · 색깔 규칙 바꾸기 · 정확한 추적 · 동체시력
- **희미한 별 찾기 → 🌟 줄무늬 별 방향 찾기 (가보르)**: 4칸 위치 고르기 대신 가보르 줄무늬 하나를 보고 줄 방향(│ ─ ╱ ╲)을 맞혀요. 단계별로 방향 수(2→4), 줄 굵기(공간주파수, 별 안 줄 3→8개), 시작 대비, 노출 시간, 둘레 위치(4·5단계)가 바뀌고, 대비는 적응형 계단법으로 흐려져요. 단계 아래 🛠 버튼으로 방향 수·굵기·처음 진하기·자리를 직접 골라 연습(별 없이 기록만)도 돼요. 정답률·시행별 반응시간·방향별 정답 기록. 화면 크기에 맞춰 별·버튼 크기를 계산해서 가로 휴대폰(844×390)에서도 겹치지 않아요. 최고 기록 키 `seeon.faint6.*`(예전 게임과 비교 안 함).
- **번개 도형 터치**: 목표 칸에 도형만 표시(이름 글자 뺌). 도형 11가지(하트·십자·초승달·육각형·오각형·타원 추가), 단계별 7→8→9→10→11가지.
- **헷갈리는 색깔**: 색 9가지(하늘·연두 추가, 파랑·초록을 더 진하게 → 파랑↔하늘, 초록↔연두 헷갈림), 단계별 7→8→9→9→9가지. 2단계부터 지시판이 🎨 색깔 / 📖 뜻 으로 바뀌어요(규칙 전환). 바뀔 때 지시판이 빙글 돌고 안내 문구가 바뀜. 지시별·전환/반복 정답률·반응시간, 전환 비용 기록. 시간 4→2.1초. 최고 기록 키 `seeon.nova3.*`.
- **지그재그 따라가기 · 달님 그네**: 안내 문구를 "빠르게보다 정확하게, 놓치지 않고, 여러 번 되풀이" 중심으로.
- **슝슝 야구공**: "작고 빠를수록 동체시력이 더 크게 자극돼요" 안내(단계마다 공이 작아지고 빨라지는 구조 설명). 지그재그·달님에도 익숙해지면 작게·빠르게 안내.
- **줄무늬 별 상자 테두리 수정**: 가보르 투명도(가우스)가 네모 캔버스 끝에서 잘려 테두리 쪽에 약 5% 투명도가 남았고, 회색 바탕이라 어두운 화면에 네모 상자 모양이 비쳤어요. 가우스를 캔버스 안 원 가장자리에서 정확히 0이 되게 바꿔 테두리가 없어졌어요.
- **달님 그네**: '톡' 대신 기기에 맞게 "마우스로 클릭(스페이스 키도 돼요)" / "화면을 손가락으로 터치"로 안내.
- **가로 휴대폰 화면**: 우주 모험 지도 — 위 막대를 한 줄로 납작하게(지도 버튼을 가운데로, 진한 바탕) + 지금 위치를 막대 아래 칸 가운데로 맞춰 행성이 지도 버튼 밑에 겹쳐 보이지 않게. 보호자 리포트 — 목차 줄이 잘리는 끝을 흐리게 하고, 보고 있는 목차가 잘린 곳에 있으면 목차 줄을 밀어 보이게. 667×375 홈 — 위 막대 버튼이 화면 밖으로 밀리던 것 수정.
- **전면 점검 (2026-10-09)**: 게임 18개 무작위 조작(컴퓨터·휴대폰), 모든 게임 기록 형식, 우주 모험, 회원·쿠폰·비회원 제한, 관리자 화면, 화면 크기 6가지 159개 화면 점검. 고친 것: 번개 도형 — 게임 중 나가기 창을 열었다 닫으면 Go/No-Go 개수가 1씩 부풀던 것 · 줄무늬 별 — 한 문제도 안 풀고 끝나면 문턱이 0%(최고 기록처럼)로 남던 것 · 관리자 게임 분석 — 기간을 바꿨을 때 보던 게임이 그 기간에 기록이 없으면 말없이 접히던 것(안내 문구, 기간을 넓히면 다시 펼침).
