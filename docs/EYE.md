# 📷 카메라 눈 움직임 분석 (참고용)

전면 카메라나 웹캠으로 게임 중 눈동자와 머리의 움직임을 살펴보고, 판이 끝나면 "이번 판을 얼마나 제대로 연습했는지"를 보여 주는 선택 기능이에요.

## 쓰는 게임
| 게임 | 방식 | 보는 것 |
|---|---|---|
| 달님 그네 · 지그재그 따라가기 · 우주 나침반 | 따라 보기 | 눈이 움직이는 목표를 따라간 정도(목표 위치와 시선 추정값의 상관계수, 0.4초까지 늦게 따라가도 인정), 목표 대비 눈이 움직인 폭 |
| 쌍둥이 행성 | 눈 모으기 | 두 눈이 함께 안쪽으로 모인 정도(보정 때 가운데를 볼 때와 비교)와 유지 시간 |
| 별빛 잇기 | 홱보기 | 숫자가 뜬 쪽으로 0.9초 안에 시선이 옮겨 간 비율과 걸린 시간 |
| 공통 | — | 얼굴이 보인 비율, 머리를 고정한 비율(보정 때보다 7° 이상 돌리지 않은 비율), 1분당 눈 깜빡임 |

**연습 효과 기대**(높음 · 보통 · 낮음)는 위 숫자로 만든 "이번 판을 목표한 눈 움직임으로 연습한 정도"예요. 시력이 얼마나 좋아질지 예측하는 값이 아니에요.
- 따라 보기: 따라간 정도 65% + 머리 고정 35%
- 눈 모으기: 모으기 크기 70% + 머리 고정 30%
- 홱보기: 시선 이동 정확도 70% + 머리 고정 30%
- 0.7 이상이면 높음, 0.45 이상이면 보통, 그보다 낮으면 낮음. 얼굴이 절반 이상 안 보이면 계산하지 않아요.

## 동작 순서
1. 게임 화면 위 **📷 눈 측정** 버튼을 누르면 안내 창이 떠요.
   - 회원은 "(선택) 결과 숫자를 계정에 저장"에 체크할 수 있어요.
   - "🔁 다음부터 게임을 시작하면 자동으로 측정"은 기본으로 켜져 있어요. 조종사마다 저장되고(`seeon.eyeauto`, 계정과 함께 동기화), 계정 창의 "🔁 눈 측정 자동으로 켜기" 스위치로 바꿀 수 있어요.
2. 분석 도구(Google MediaPipe Face Landmarker)를 내려받아요. 처음 한 번은 수 초가 걸려요.
3. 카메라 권한을 허용하면 **5곳 눈 맞추기(보정, 약 8초)**를 해요. 별이 가운데 → 왼쪽 → 오른쪽 → 위 → 아래로 이동해요.
4. 게임을 하는 동안 초당 약 20번 눈 blendshape(eyeLookIn/Out/Up/Down, eyeBlink)와 머리 회전을 읽어요. 왼쪽 아래 작은 카메라 창의 상태 표시가 초록색이면 얼굴이 잘 보이는 거예요.
5. 판이 끝나면 결과 화면에 "📷 카메라 눈 움직임 분석" 카드가 나와요.
6. 게임을 닫거나, 지원하지 않는 게임으로 가거나, 다른 앱으로 전환하면 카메라가 자동으로 꺼져요.

### 자동 측정
자동 측정이 켜져 있으면 지원 게임(달님 그네 · 지그재그 · 우주 나침반 · 쌍둥이 행성 · 별빛 잇기)의 단계/시작 버튼을 누를 때 카메라와 보정이 먼저 시작되고, 보정이 끝나면 게임이 바로 시작돼요. 우주 모험에서 이 게임들이 나올 때도 같아요.
- 준비 화면의 "이번엔 측정 없이 할래요"(보정 화면에서는 "측정 없이 시작")를 누르면 카메라 없이 바로 게임을 해요.
- "자동 측정 끄기"를 누르면 설정이 꺼지고 게임은 그대로 시작해요.
- 게임 중에 "측정 중" 버튼으로 카메라를 끄면, 그 게임을 나갈 때까지는 자동으로 다시 켜지지 않아요.
- 카메라 권한이 거부되거나 얼굴을 찾지 못하면 측정 없이 게임을 시작해요.

### 게임을 나갈 때 결과 창 (규칙)
카메라를 켠 채로 게임을 나가면 **항상** 결과 창이 떠요.
1. 하던 판이 있으면(끝까지 하지 않았어도) 나가기 전까지 측정한 만큼 보여 줘요. 게임 기록이 없으니 저장되지는 않아요.
2. 하던 판이 없으면, 이번 측정에서 마지막으로 끝낸 판의 결과를 보여 줘요.
3. 보정만 하고 게임을 안 했으면 "아직 결과가 없어요" 안내가 떠요.
- 자유 훈련(달님 그네 · 지그재그)은 15초 이상 하면 기록이 남고, 그 결과가 나갈 때 창으로 떠요.
- 스토리 모드에서는 결과 창을 닫은 뒤에 지도 애니메이션이 이어져요.

### 결과 카드에서 나중에 저장하기
회원이 처음에 "결과 저장"을 체크하지 않았어도, 끝까지 한 판의 결과 카드(결과 화면·나가기 창)에 **"📮 이 결과 저장하기"** 체크가 나와요.
- 체크하면 저장 동의(`eye_metrics`)가 기록되고, 방금 한 판의 게임 기록(cid)에 요약 숫자가 붙어요. 이미 서버에 올라간 기록이면 `seeon_attach_eye` RPC로 붙여요.
- 이후 측정 결과도 자동으로 저장돼요. 계정 창에서 끄면 저장된 숫자까지 지워져요.

## 개인정보 · 보안
- 카메라 영상은 **브라우저 안에서만** 분석하고 곧바로 버려요. 영상·사진·얼굴 특징점은 저장하거나 서버로 보내지 않아요.
- 서버에 남는 건 보호자가 저장에 동의한 경우의 **요약 숫자**뿐이에요. 게임 기록 `seeon_records.m`에 `e_`로 시작하는 키로 들어가요.
  - `e_fv` 얼굴 보임 비율 · `e_hs` 머리 고정 비율 · `e_bl` 분당 깜빡임 · `e_q` 연습 효과 기대(0~1) · `e_n` 분석한 장면 수
  - `e_fo` 따라간 정도 · `e_rg` 움직인 폭 · `e_cv` 눈 모으기 크기 · `e_ch` 모은 시간(초) · `e_sc` 시선 이동 정확도 · `e_lt` 걸린 시간(ms)
- 동의는 `seeon_consents`에 `eye_metrics` 종류로 기록돼요. 계정 창에서 끄면 철회가 기록되고, 저장돼 있던 `e_` 숫자도 서버와 기기에서 모두 지워져요.
- 비회원은 결과를 화면에서만 보여 주고 저장하지 않아요. 나중에 가입해도 눈 숫자는 옮겨지지 않아요.
- 배지용 측정 횟수(`seeon.eyestat`)는 기기에만 두고 서버로 보내지 않아요.
- 약관(제6조), 개인정보 처리방침(1항 표, 5항 표, 8항), `legal.html#eye` 안내에 반영했어요.

## 한계 (보호자·운영자가 알아 둘 것)
- 웹캠 blendshape는 전용 시선 추적 장비보다 훨씬 거칠어요. 조명, 안경 반사, 카메라 각도, 화면과의 거리에 따라 값이 달라져요.
- 세로 방향 움직임은 가로보다 덜 정확해요. 그래서 따라 보기 점수는 목표가 많이 움직인 방향에 가중치를 둬요.
- 쌍둥이 행성의 눈 모으기는 "두 눈이 안쪽으로 모이는 움직임이 보였는지"만 알려 줘요. 실제 융합(하나로 보임) 여부는 아이의 "하나로 보여요" 응답으로 판단해요.
- **의료기기가 아니며 진단·치료 효과를 약속하지 않아요.** 광고·안내 문구에서도 "시력이 좋아진다" 같은 표현은 쓰지 마세요.

## 설정
1. Supabase SQL Editor에서 `supabase/eye.sql`을 실행해요. `members.sql` 다음에 실행하고, 여러 번 실행해도 안전해요. (나중에 저장하기용 `seeon_attach_eye` 함수가 추가됐으니 예전에 실행했어도 한 번 더 실행해요.)
2. 기본값으로 분석 도구는 jsDelivr(`@mediapipe/tasks-vision@1.0.1`), 모델은 Google Storage에서 내려받아요. 직접 호스팅하려면 `config.js`에 아래처럼 적어요.
```js
window.SEEON_CONFIG = { /* …기존 값… */, eye: {
  bundle: "vendor/mediapipe/vision_bundle.mjs",
  wasm:   "vendor/mediapipe/wasm",
  model:  "vendor/mediapipe/face_landmarker.task"
}};
```
